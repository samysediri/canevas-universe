# Canevas 2.0 — Scientific core v1

Canevas 2.0 is a research program, not an established physical theory.

## Core equation

For physical parameters theta and an explicitly defined selection condition O:

P(theta | O) ∝ P(O | theta) mu(theta)

This is Bayesian bookkeeping. Canevas becomes a distinct theory only if it independently constrains the measure mu(theta), the selection likelihood P(O|theta), or both strongly enough to make preregistered predictions.

## Retained principles

1. Infinite opportunity alone does not imply eventual realization; recurrence requires an explicit probability law and dependence structure.
2. Observer/structure selection must be explicit. Consciousness is not assumed as a fundamental weight without an independent physical theory.
3. The measure is part of the model. Temporal weighting, domain counting, and observer counting may not be chosen after seeing the target value.
4. Finite local entropy/information capacity does not imply global infinity or literal duplicate universes.
5. Historical results are exploratory unless they were genuinely preregistered before the relevant target was inspected.

## Removed from the scientific core

The current scientific model does not assume that: global infinity is established; infinity guarantees every possibility; consciousness is necessarily fundamental or eternal; human birth rank predicts extinction; delayed-choice proves backward causation; the Fermi paradox proves universal civilization mortality; or finite local state capacity implies repeated universes.

## Main empirical branch

The strongest tractable branch is cosmological parameter selection, especially zeta = rho_CDM/rho_b and later Lambda. Historical zeta calculations show substantial epoch dependence, so time weighting is explicitly a measure problem rather than a nuisance parameter to choose post hoc.

## Evidence rules

A new result counts as Canevas-2 evidence only when the target value is not used to define the score, the physical proxy is independently motivated, all measure choices are frozen before output, nuisance variants are propagated, boundary/failure cases remain in the record, an adversarial alternative is tested, and the result replicates on a construction not used to invent the measure.

## Sequence

C2-M1: retrospective measure audit of historical zeta results. Post-hoc only, never new evidence.
C2-M2: preregister a new independently motivated time-integrated measure.
C2-PRED1: generate a blind predictive distribution for zeta and reveal zeta_observed only afterward.
C2-ADV1: compare against null/nonselective priors and alternative physical proxies.
C2-REP1: independent replication.

## Falsification

The branch is weakened if independently motivated measures move the prediction by orders of magnitude, observed parameters lie persistently in tails, or agreement disappears under replication. It is strengthened only if independent preregistered measures produce overlapping predictive regions containing the observed value without target tuning.
