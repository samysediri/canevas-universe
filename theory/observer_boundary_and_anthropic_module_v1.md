# Canevas 1.0 — Observer-boundary theorem attempt + anthropic/self-location module

Status: theory work only. No cosmological parameter is being fit in this document.

## Part I — Attempted theorem: finite/local information is necessary for a determinate experience

### Definitions

Let the total physical state be X. Let an observer-like subsystem O possess an internal state o drawn from a set O_states. Let E denote the rest of the physical state relevant to O.

A determinate experience at an instant requires at minimum:

1. **Distinguishability**: at least two possible internal experiential states o1 != o2 can in principle be discriminated.
2. **Local encoding**: the current experiential state is encoded by some proper subset/effective coarse-graining of the total state X, rather than requiring simultaneous access to every independent degree of freedom of X.
3. **Temporal correlation if memory is claimed**: what is called memory requires current internal variables to correlate with variables associated with earlier physical states.

### Proposition P1 — No distinguishability, no determinate content

If every physically possible internal state of O is experientially identical, then there is no physically representable distinction between one experiential content and another. Thus a determinate experience with content presupposes distinguishable states.

This is close to definitional, not a new physical law.

### Proposition P2 — An observer is relationally bounded

To speak meaningfully of an observer O and an environment E requires a partition, exact or effective, of degrees of freedom. If O = X with no relational distinction whatsoever between an internal state and anything external, terms such as observation, input, memory and environmental correlation lose their ordinary physical meaning.

This does NOT prove that consciousness metaphysically requires a literal spatial boundary. It supports the weaker claim that an observer description requires an informational/causal partition.

### Proposition P3 — Memory implies asymmetric correlations, not necessarily a finite universe

Memory does not logically require the whole universe, humanity, or cosmic time to be finite. It requires a present state of O that contains correlations carrying information about other states/events. Thus the original intuition that birth/death provide necessary finitude is weakened to:

> A determinate observer-history requires locally bounded information and differentiated states; global finitude does not follow.

### Counterexample program

The proposition would be weakened if a coherent model can exhibit all of the following simultaneously:
- experience with determinate content;
- no distinction, even effective, between observer and environment;
- no distinguishable internal states;
- and, where memory is claimed, no physical correlations representing past information.

Absent such a model, the "observer boundary" claim remains a conceptual necessity of an information-processing description, not yet a distinctive prediction of Canevas.

## Part II — Birth-time intuition as a self-location problem

### The intuition

The motivating observation is that one finds oneself born during an unusually populous, rapidly changing technological epoch. Intuitively this can feel like an implausibly precise historical placement.

This intuition must be decomposed before being used as evidence.

### Effect A — Population-density selection

Conditional on being a randomly sampled human birth from births that have occurred, epochs with more births are automatically more likely. Rapid population growth therefore makes a recent birth *less* surprising under a birth-weighted sampling rule.

Hence "I was born when population was huge" is not by itself evidence of cosmic selection.

### Effect B — Technological observer selection

Many descriptions one can make about one's own situation — literacy, scientific concepts, computers, cosmology — are only available to observers after substantial cultural and technological development. Conditioning on being an observer capable of asking the Canevas question strongly biases the reference class toward technologically mature eras.

Therefore "I exist in a technological era" also contains a potentially large selection effect.

### Effect C — Doomsday/self-sampling tension

A different question is one's rank among all observers/humans who will ever exist. Under a Self-Sampling Assumption (SSA)-like rule, treating oneself as approximately random within a specified reference class, an early rank can disfavor futures containing vastly more members of that class. This is the family of arguments usually called the Doomsday Argument.

However this conclusion is NOT axiomatically implied. It changes or can disappear under alternative self-locating principles such as Self-Indication Assumption (SIA), different reference classes, observer-moment weighting, duplication rules, and different treatments of infinite populations.

### Integration rule for Canevas 1.0

The birth-time/Doomsday idea is therefore NOT an axiom and NOT evidence yet. It is recorded as an optional module:

**H_SL (self-location hypothesis):** conditional on a precisely defined observer/reference class and physical world-model, indexical location obeys a specified sampling rule.

No prediction may be reported until all of the following are specified before looking at the desired conclusion:
1. reference class (humans, conscious observers, observer-moments, etc.);
2. sampling unit;
3. SSA/SIA/other rule;
4. treatment of duplicates;
5. treatment of infinite populations;
6. conditioning information (e.g. technological competence);
7. population-history model.

If conclusions change strongly across reasonable choices, the Doomsday inference is classified as measure-dependent rather than a Canevas theorem.

## Part III — Relation to Canevas axioms

Possible logical chain:

A4: determinate experience requires limits/differentiation
-> observer histories are local/informationally bounded
-> an observer can possess indexical uncertainty about which observer-history it instantiates
-> a self-location probability problem exists

The final step does NOT determine the probability measure. A new principle H_SL is required.

Therefore:

Canevas axioms -> existence of a self-location problem (plausible)
Canevas axioms -/-> unique SSA/SIA rule (not derived)
Canevas axioms -/-> Doomsday conclusion (not derived)

## Part IV — Next falsification task

Before using population history or Doomsday reasoning numerically, perform a reference-class invariance test:

- define several defensible reference classes and sampling rules before calculation;
- condition explicitly on the information that the observer is capable of modern technological/cosmological reasoning;
- ask whether the apparent temporal "coincidence" survives;
- reject any claimed Canevas prediction that flips sign under reasonable self-location rules.

This module should remain separated from cosmological parameter fitting and from the failed distinguishability-as-probability hypothesis.
