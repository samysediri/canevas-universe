# Canevas 1.0 — T3.2 Relational State Principle v1

## Goal
Test whether the Canevas idea "no physically privileged external label/reference" yields at least one nontrivial mathematical restriction on physical state space or dynamics WITHOUT assuming Lorentz symmetry, Hilbert space, spacetime dimension, Standard Model gauge groups, or observed particle content.

This document is a structural derivation audit, not an empirical fit.

---

# 1. Minimal primitive

Assume only the following candidate Canevas principle:

R0 — Physical irrelevance of external relabelling
If two mathematical descriptions differ solely by labels/coordinates/bookkeeping that have no relational physical consequence within the Canevas, they represent the same physical possibility.

This is stronger than saying "probabilities should not depend on file names" but weaker than assuming any known gauge theory.

Status: CANDIDATE BRIDGE from A1-A4 / absence of external privileged labels.

---

# 2. Description space versus physical state space

Let D be a space of mathematical descriptions d.

Define an equivalence relation ~ on D:

d1 ~ d2 iff every physically meaningful relational fact represented by d1 is identical to that represented by d2.

Then the physical state space cannot consistently be D itself if D contains redundant descriptions.

The physical state space must instead be represented by equivalence classes:

S_phys = D / ~

where [d] denotes the equivalence class (orbit) containing description d.

## T3.2-A — Quotient-state restriction
If R0 is accepted, physically distinct possibilities are elements of D/~, not arbitrary elements of D.

Status: DERIVED CONDITIONAL ON R0.

This is already a nontrivial mathematical restriction and does not require specifying any known gauge group.

---

# 3. Observable restriction

Let O:D -> R be a proposed physical observable.

If d1 ~ d2 represent the same physical state, consistency requires

O(d1)=O(d2).

Therefore every genuine physical observable must be constant on equivalence classes and descend to a well-defined function

O_phys : D/~ -> R.

## T3.2-B — Relational observable theorem
No quantity that varies only under physically redundant relabelling can itself be a physical observable.

Status: DERIVED CONDITIONAL ON R0.

This is the abstract core of gauge/coordinate-invariant observables, obtained without assuming a specific gauge group.

---

# 4. Dynamics restriction

Suppose F_t:D -> D is a candidate time-evolution/dynamical map at the description level.

For the dynamics to define a unique physical evolution on D/~, it must satisfy:

if d1 ~ d2, then F_t(d1) ~ F_t(d2).

Equivalently, F_t must preserve equivalence classes enough to induce a well-defined map

Fbar_t : D/~ -> D/~.

## T3.2-C — Projectable dynamics restriction
A dynamical law that sends two redundant descriptions of the same physical state into physically inequivalent futures is inadmissible.

Status: DERIVED CONDITIONAL ON R0.

This is a genuine restriction on dynamics independent of any empirical constants.

---

# 5. Generative-measure restriction

From T3, let M_dyn be the generative measure over physical realisations.

If redundant descriptions are physically identical, a fundamental measure cannot assign extra physical weight merely because one physical state possesses more mathematical descriptions than another.

Therefore the fundamental measure must be defined on physical equivalence classes, or be a description-space measure whose pushforward to D/~ is invariant under arbitrary changes in redundant parameterisation.

Schematically:

M_phys(A) = M_desc(pi^{-1}(A))

where pi:D -> D/~ is the quotient map, provided the description-space construction handles redundant orbit volume without turning it into physical multiplicity.

## T3.2-D — No gauge-orbit multiplicity rule
Pure redundancy may not be interpreted as additional physical copies.

Status: STRONG DERIVED CONSEQUENCE OF R0 + probability label invariance.

This directly connects relational redundancy to the earlier measure problem: counting descriptions is not the same as counting physical realisations.

# 6. Group-action special case

If the redundancy relation is generated by transformations g in some group G acting on D, then

d ~ g.d

and physical states are group orbits:

S_phys = D/G.

Then physical observables obey

O(g.d)=O(d)

and projectable dynamics must respect the orbit structure.

Important: T3.2 does NOT determine G.

It establishes only the abstract structure that IF redundancy transformations form a group, physical states are orbit classes rather than raw descriptions.

This is the mathematical skeleton shared by gauge redundancy, but no claim is made that Canevas has derived U(1), SU(2), SU(3), diffeomorphism invariance, or any observed interaction.

# 7. Continuous local redundancy

A stronger hypothesis can now be stated clearly rather than smuggled in:

R1 — Local redundancy hypothesis
The physically irrelevant relabelling freedom can vary independently over regions/locations rather than only globally.

If R1 is assumed, then comparing internal states at neighbouring locations generally requires a rule for relating their local conventions. In differential-geometric language this motivates connection-like structure.

However:
- R0 alone does NOT imply R1;
- R1 does NOT determine the group G;
- a connection does NOT yet imply a specific Yang-Mills action;
- spacetime itself has not been derived.

Therefore local gauge fields are a possible NEXT bridge, not a result of T3.2-A through D.

# 8. Toy proof that quotienting changes predictions

Consider a description with two variables (x,lambda), but suppose lambda is pure redundancy: (x,lambda1) ~ (x,lambda2) for all lambda.

If one naively samples uniformly over a finite rectangular description space, the physical weight assigned to x can depend on the arbitrarily chosen range of lambda.

After quotienting by ~, the physical state is simply x and that arbitrary multiplicity disappears.

Thus R0 has operational consequences for measure construction: redundant coordinates can create spurious priors/volume factors if not removed or correctly gauge-fixed.

This mirrors the failure mode previously seen when arbitrary parameter-space volume was mistaken for physical probability.

# 9. Does T3.2 meet the preregistered success criterion?

Preregistered success criterion from T3.1:
"Produce at least one nontrivial mathematical restriction on state space or dynamics that is NOT inserted by assuming known Standard Model/GR symmetries."

Result:
PASS, in the limited structural sense.

1. physical state space must be quotient-like D/~ when redundant descriptions exist;

These are nontrivial but framework-level restrictions. They do NOT yet predict a particle, force, constant, spacetime dimension, or numerical observation.
